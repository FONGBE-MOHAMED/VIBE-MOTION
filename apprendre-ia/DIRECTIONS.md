# Direction

L'étape des trois directions a été sautée à la demande de l'utilisateur : le storyboard a été écrit directement sur la
direction que porte le script choisi (version B, « Pas pour moi »).

## Direction unique : « La frise des excuses »

- **Le lieu que la caméra parcourt** : une frise du temps dans un bureau de nuit, avec trois stations (2000 : écran
  cathodique ; 2010 : smartphone ; 2026 : portable). Après le pivot, le papier clair et l'assistant IA.
- **Le fil des objets-ponts** : le post-it jaune « Pas pour moi » (il se colle, tombe, revient, perd son « Pas », devient
  le bouton) ; l'horloge (elle avale le temps, puis le rend) ; le champ de saisie (le gag, puis la demande) ; la tasse
  de café.
- **Images de style** : une par plan, `styleframes/P01.html` à `P22.html` (PNG avec
  `python3 .claude/skills/motion-design/scripts/render-styleframes.py apprendre-ia`), réunies dans la planche
  `planche/planche.pdf`.
